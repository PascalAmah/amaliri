Breevs is a decentralized elimination game running on the Stacks Blockchain.

Players enter rounds, compete, and get eliminated until one winner claims the prize pool. All game logic — entry fees, round progression, and prize distribution — is encoded in Clarity smart contracts, making the rules fully transparent and tamper-proof on-chain.

The frontend is built with Next.js and connects directly to the Stacks network via the Stacks.js SDK. The backend handles off-chain coordination and game state, while the blockchain handles trust and settlement. A project that pushed me deep into smart contract architecture and the intersection of web3 UX and traditional web development.
