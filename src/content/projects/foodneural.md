FoodNeural leverages machine learning to assess the environmental footprint of our food choices.

By processing large datasets of food products, the AI model evaluates key metrics such as greenhouse gas emissions, water usage, and land impact. The backend is powered by a Flask API that integrates with `scikit-learn` and `pandas` for data analysis, while the frontend is a responsive React application.

This project aims to empower users to make informed, sustainable dietary decisions.
