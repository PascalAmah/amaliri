BarqPix is a real-time event media platform that revolutionizes how photos are shared at events using QR-based access.

The platform provides an isolated environment for each event, ensuring that media is only accessible to authorized attendees. I led the backend development, focusing on robust and scalable media uploads using Firebase, along with an Express.js server to handle custom business logic and AI processing.

By leveraging asynchronous processing, we achieved high throughput for image uploads without blocking the user experience.
