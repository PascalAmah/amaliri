EduPulse is an adaptive microlearning platform currently in development.

It uses AI/ML to tailor bite-sized educational content and quizzes to a user's behavior, mood, and learning goals. The stack includes a Node.js backend with MongoDB for flexible data storage, and a React frontend to deliver a smooth and engaging user experience.

The ultimate goal is to revolutionize personal education through highly adaptive learning paths.
