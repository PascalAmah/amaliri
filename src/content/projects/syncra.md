Syncra is an npm package that provides offline-first sync logic for modern applications.

It handles the hardest parts of offline-capable apps: data synchronization when connectivity is restored, conflict resolution when multiple clients modify the same data, and transparent offline state management so users never hit a wall without internet.

The package ships alongside a landing page and a developer dashboard for monitoring sync activity, queue depth, and conflict resolution history. Built with NestJS for the backend API and Redis for queue management.

Available on npm — designed for teams who want offline-first behaviour without writing the sync layer from scratch.
